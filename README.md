# study-on-canvas

[한국어](README.md) · [English](README.en.md)

- LLM과 대화하며 새로운 개념을 배울 때, 대화 내용을 HTML 파일로 시각화하여 학습을 도와주는 Claude Code 플러그인입니다. 

> 플러그인을 만들게 된 배경
> - 모르는게 생겨서 LLM에게 A를 물어보면 종종 "이 다음엔 B에 대해서 더 알아볼까요?"라고 물어보는 경우가 있습니다. 그래서 B를 물어보면, C가 나오고, 때로는 2개 이상의 후속 개념을 제안해줄 때도 있는데요. 좀 전에 나왔던 C를 물어봐야지, 하고 기억만 해두고 있다가 LLM이 제안한 다른 개념을 그대로 따라가느라 까먹을 때가 있습니다. 대화를 지속하다보면 그래서 내가 오늘 짚고 간 개념이 무엇무엇이었지? 하고 헷갈릴 때도 있구요.
> - LLM이 내게 알려주는 `개념 지도`를 시각적으로 표현하고, 공부한 기록도 남길 수 있도록 html 파일을 만들어주는 플러그인을 만들게 되었습니다.

### 지원하는 LLM

- Claude Code

## 사용법

### 1. 플러그인 호출과 함께 내가 배우고 싶은 개념을 물어보세요. 

- slash 명령어로 플러그인을 직접 호출할 때: 플러그인 호출 명령어와 함께 궁금한 질문을 입력해 주세요.

```plain_text
/study-on-canvas:study-on-canvas Attention is all you need라는 논문에서 Attention이 어떤 개념인지, 이 개념이 어떻게 지금의 생성형 AI를 만드는데 기여했는지 알고 싶어.
```

- 자연어로 호출할 때: "캔버스", "canvas", "학습 노트" 를 언급하면 슬래시 명령 없이도 플러그인이 발동합니다.

```plain_text
캔버스로 대화하자. Attention is all you need라는 논문에서 Attention이 어떤 개념인지, 이 개념이 어떻게 지금의 생성형 AI를 만드는데 기여했는지 알고 싶어.
```

### 2. LLM이 html 파일을 저장할 경로를 묻습니다. 

- 기본값은 플러그인을 실행한 경로에서 learning-notes라는 폴더를 만들어 그 안에 저장합니다.
- 그 외 내가 원하는 경로가 있다면 2번을 선택하거나 3번 선택 후 직접 입력해 주세요.

![파일 저장 경로 묻기](./images/파일-저장-경로-묻기.png)

### 3. html 파일이 만들어지고 자동으로 켜집니다. 

- html 파일이 생성 완료되면 OS 기본 브라우저로 켜집니다.
- LLM이 만들어준 설명문을 볼 수 있습니다. 
- 화면 우측에는 이 다음에 톺아보면 좋을 개념을 LLM이 추천해 줍니다. 
- **편리하게 사용하려면 다음 스크린샷처럼 LLM과의 대화창과 html 파일을 한 모니터에 모아 두면 좋습니다.**

![html 레이아웃](./images/html-레이아웃.png)

### 4. LLM이 추천한 하위 개념이 아닌, 설명문을 보고 궁금해진 내용을 물어봐도 됩니다. 

- 3번 상태에서 저는 터미널에 다음과 같은 질문을 입력했습니다. 

```plain_text
Attention 개념을 더 깊게 들어가기 전에 RNN과 CNN의 기술적 원리를 알고 싶어.
```

- 다음 질문에 대한 LLM 작업이 완료되면 브라우저를 새로고침해주세요.
- (1) 새로 작성된 설명문을 탭 버튼 형태로 볼 수 있습니다. 
- (2) 추천 하위 개념 목록에서 설명문이 작성된 개념은 노란색으로 표시됩니다. 
  - 노란색 개념을 누르면 해당 설명문으로 바로 이동합니다.

![후속 개념 물어보기](./images/후속-개념-물어보기.png)

### 5. 개념 지도 보기

- html 우측 상단에 지도 아이콘을 눌러 주세요. 
- 지금까지 살펴본 개념 목록을 상/하위 구조도로 볼 수 있습니다. 
- 설명문이 생성된 개념은 노란색으로 표시됩니다. 누르면 해당 설명문으로 바로 이동합니다. 

![개념 지도](./images/개념-지도.png)

## 플러그인 커스텀하기

### html UI 디자인

- `study-note.html` 파일을 템플릿으로 사용합니다. UI 변경 등 전체적인 변경을 원하면 템플릿을 수정해 주세요.
- 예를 들어, UI 색상 변경이 필요하면 `:root` CSS 변수를 고치면 됩니다.

### 추천 후속 개념 개수 줄이기/늘리기

- 추천 후속 개념은 1~3개로 고정되어 있습니다. 
- 더 적게/많이 후속 개념을 추천 받으려면 `SKILL.md 핵심 원칙 1번`을 수정해 주세요.

## 플러그인 설치

Claude Code에서:

```
/plugin marketplace add winter-blanket/study-on-canvas
/plugin install study-on-canvas@study-on-canvas
```

## 지원 언어

- 플러그인이 생성하는 html UI는 한국어가 기본값이며 영어도 지원합니다.
- 처음 플러그인을 호출할 때 쓰인 언어로 html을 생성합니다.

## 파일 구조

```
.claude-plugin/
  plugin.json          플러그인 매니페스트
  marketplace.json     단일 플러그인 마켓플레이스 정의
skills/study-on-canvas/
  SKILL.md             스킬 본문 — 실행 플로우와 HTML 조작 사양
  template/
    study-note.html    노트 템플릿 (단일 파일, 외부 의존성 없음)
```

- 템플릿은 `{{TITLE}}`·`{{DATE}}` 같은 플레이스홀더와 `<!-- TABS_INSERT -->` 류의 마커만 갖고 있습니다.
- 플러그인은 파일 전체를 다시 쓰지 않고 이 마커 사이에만 삽입합니다.
